# 身份安全参数 identity-v1

日期：2026-10-19。工程默认参数以 [security-policy.ts](../packages/config/src/security-policy.ts) 为机器来源，调整须记录版本、影响、测试和已有挑战/会话的处置；不能由普通店铺配置覆盖。

| 参数 | 默认值 | 行为 |
|---|---|---|
| 已登记 MFA 的登录挑战 | 5 分钟 | 到期即拒绝；新认证签发新挑战 |
| 登记授权及待登记因子 | 最长 10 分钟 | 因子截止时间不晚于原授权截止；重开不续期 |
| 邀请 | 24 小时 | 到期不可接受；可由有权员工显式重发新版本 |
| 邀请重发 | 最小间隔 60 秒，同一邀请每小时最多发送 5 次 | 首次发送计入额度；重发不重置小时窗口；同时按员工/实例/IP 限流，禁止重建邀请绕过额度 |
| 挑战验证失败 | 同挑战最多 5 次 | 达限使挑战失效；仍受账号/IP 限流约束 |
| 身份写请求 IP 限流 | 同 IP 每 15 分钟最多 60 次 | 使用直连对端地址；代理部署需经审核配置可信代理，不能直接信任转发头 |
| 账号失败及冷却 | 15 分钟内 5 次失败，冷却 15 分钟 | 延续开发执行规格；不能换挑战绕过 |
| bootstrap 窗口 | 明确开启后最长 15 分钟 | 首店主建立后永久关闭；超时只可授权运维重新开启未初始化实例 |
| 后台会话 | 空闲 30 分钟，绝对 12 小时 | 活动只滑动空闲截止，不延长绝对截止 |
| 密码重设 | 30 分钟，一次性 | 成功后撤销旧会话，保留 MFA 要求 |
| 随机凭据 | 32 字节密码学随机数 | base64url 传输；服务端只保留 token 摘要，通知投递短时秘密须加密 |
| 恢复码 | 每组 10 个，每个 20 字符 | 使用密码学随机源、至少 32 字符的无歧义字母表；至少 100 bit 随机性；哈希保存，一次性消费 |
| 过期秘密清理 | 每 15 分钟扫描 | 先按到期时间拒绝请求，清理任务延迟不延长有效期 |

恢复码生成、TOTP/时间步防重放、Argon2id、账号/IP 持久限流和身份数据库已实现并通过真实集成测试。邀请通知/持久生命周期、清理 Worker 和安全参数的受控配置管理仍未实现；当前代码默认值不能被当作已有生产部署。详见 [身份实现说明](R1_IDENTITY_IMPLEMENTATION.md)。

过期 invitation/challenge 保留无秘密的审计关联；待 TOTP 秘密在过期/撤销时清除；历史审计保留期沿用客户确认策略。会话管理记录与审计可保留，但不继续保留可用凭据。正式环境须用数据库时间/可信 UTC，异常或不可解析时间直接拒绝，不能把清理作为有效性判断。
