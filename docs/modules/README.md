## 共同产品约束

- 商店采用逐客户独立部署和独立数据空间；本项目不做多租户 SaaS。
- 访客结账无需登录；会员使用可选 OTP 登录，M10 覆盖后台档案、等级/积分/权益和会员中心。
- 语言、货币、时区、付款、配送和市场策略由店铺配置，但开放市场仍须审批。
- 支付、通知和物流使用可替换的服务适配器。
- 烟草作为行业配置包处理；地区、商品、广告、支付和配送的可用性须先由业主完成适用规则审查。
- 由于未取得旧站后台和数据库，数据迁移不在当前范围内。

端到端生产交付需同时满足 [生产就绪验收清单](../PRODUCTION_READINESS_ACCEPTANCE.md)；跨模块固定规则见 [开发执行规格](../DEVELOPMENT_SPEC.md)。市场、服务商、政策、域名和客户页面参数仍需逐实例确认。
