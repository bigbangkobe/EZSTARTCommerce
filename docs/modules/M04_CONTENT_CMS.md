# M04 内容管理

**优先级：**P0  
**初步开发估算：**5–8 人日（仅为基础 CMS 估算；加入首页/专题陈列配置和版本预览后需重新估算）

## 产品目标
让商家不改代码即可维护店铺内容、首页陈列和必要的客户说明。

## 首期范围
关于我们、联系我们、FAQ、隐私/退换/配送说明、公告、文章；三语内容；草稿/发布；发布时间和排序；客服资料由统一设置引用。维护主题已提供的首页、分类/专题页陈列区块：选择区块类型、显示状态、区块顺序、商品/分类/内容来源、手工商品顺序或动态排序规则，并可预览后发布。可编辑各语言页面标题、slug、SEO title/description、社交分享图和索引开关；提供预览、站点地图收录和已发布 URL 变更的重定向管理。

## 主要数据对象
ContentPage；ContentTranslation；Article；ArticleTranslation；FAQItem；Announcement；HomepageSection；MerchandisingCollection；ProductPlacement；PublishVersion；PublishStatus；UpdatedBy/UpdatedAt。

## 关键业务规则
跨语言发布原子性、定时计划、版本回滚、公开/索引资格及商品资格复验按 [开发执行规格第 8.1–8.2 节](../DEVELOPMENT_SPEC.md#8-页面发布导入通知和统计的端到端流程) 执行；商品新品/销量/价格动态排序口径见第 5.4 节。
页面内容可按语言分别发布；陈列草稿必须补齐店铺已启用语言的必填内容，发布不能静默回退到另一种语言。每店/语言 URL slug 唯一；已发布 slug 修改时需预览并确认创建旧地址到新地址的 301 重定向，冲突或循环必须阻止保存。未发布草稿、预览链接、后台和非生产环境不得被站点地图收录，预览页返回 noindex 控制且链接短期有效。已发布页面只有在明确允许索引时才加入站点地图；禁用/删除页面从站点地图移除并展示处理提示。SEO title/description 支持长度提示但不截断实际内容，canonical 和多语言 alternate URL 由路由/语言配置生成，不允许手工指向其他店铺域名。免责声明/政策内容由业主提供并审核，系统不生成法律承诺。陈列配置只能使用当前客户主题已注册的安全区块和字段，不提供任意代码/脚本编辑。区块内可选手工指定商品并调整本区块优先级，或按新品、销量、价格等已支持规则动态排序；动态规则需有展示上限和稳定的同值排序，手动优先级只在手动模式启用。排序作用范围为该区块/页面，不改商品全局数据。

商品资格在发布时及前台读取/购买时均校验。手动陈列中的商品若后续下架、归档或当前市场不可售，前台立即隐藏该商品；后台保留配置并标记异常，提示运营替换。动态陈列排除不合格商品并由后续合格商品补足展示数量。缺货商品按店铺配置隐藏或显示售罄，但始终不可加购。发布版本按所有启用语言原子切换，前台不得混用新旧语言版本。定时任务按店铺时区执行；首期每页仅允许一个待执行计划，撤下计划绑定对应发布版本，不能撤下后续更新版本。计划失败时保留线上版本并告警。更改保存为草稿，版本历史不可覆盖；回滚会从历史快照创建新的发布版本。

## 验收条件
管理员可以编辑、预览、发布、取消发布各语言页面；前台按状态显示；未发布草稿不可公开访问。管理员可新增/隐藏/排序主题支持的首页、分类和专题陈列区块，选择商品或动态排序、调整本区块商品优先级、保存草稿并预览桌面/手机三语视图；可即时发布、按店铺时区定时发布或撤下，并撤回/恢复历史版本。SEO 字段、索引开关、三语 canonical/alternate、站点地图和 slug 变更重定向可复核；草稿/预览不得进入索引。动态排序下禁用手动排序控件；选择商品时，禁选项显示具体资格原因。发布后商品资格变化会触发前台重验：下架、归档、市场不可售商品立即隐藏，动态区块补足候选；手动区块保留后台配置并提示运营修复。缺译、定时冲突、过期草稿和计划失败均有明确阻断/修复提示。定时失败时线上版本保持不变且后台显示失败原因。客户主题不支持的区块明确提示需定制开发，不允许配置静默失效。

## 依赖
M00/M01、M02、M03。前台消费已发布的内容与商品陈列契约；主题预览和页面发布流程使用 M02 前台契约。
