# M05 商品导入与导出

**优先级：**P0  
**初步开发估算：**6–9 人日

## 产品目标
让商家快速录入和维护批量商品，避免手工逐条录入。

## 首期范围
CSV/Excel 模板下载；上传解析；字段/分类/SKU/价格/语言验证；预览；新增/更新模式；错误行报告；商品导出。图片支持以图片 URL 或后续约定的批量媒资方式导入。

## 主要数据对象
ImportJob（发起人、文件、模式、状态、时间）；ImportRowResult（行号、SKU、错误/警告）；ImportMapping；ExportJob；导入批次审计。

## 关键业务规则
导入先预览和验证，不允许静默部分覆盖；更新按 SKU 或商品 ID 匹配。预览明确新增、更新、跳过、错误行及价格/规格/翻译差异；重复 SKU、冲突匹配、未知字段和不支持的数据不得猜测处理。默认允许运营人员显式确认“仅应用有效行”，每行独立事务提交；错误行完全不写入。若客户要求整批原子导入，则有任一错误时整批不执行。执行前二次确认影响数量，执行中断可从行级状态幂等续跑；不能默默删除未出现在文件中的商品。库存字段不得直接覆盖现存库存，需通过独立盘点/库存调整导入产生带原因的库存流水。

- 图片远程地址导入仅允许安全的 HTTPS 资源；服务端限制重定向、文件大小/类型和下载超时，拒绝内网/本机/云元数据等目标，避免导入触发任意内网请求。无法安全导入的图片作为行级错误/警告供用户处理。
- 导出权限与商品/顾客数据权限分离；顾客资料导出按 M00 受限授权、脱敏策略和审计执行，临时导出文件有过期时间，下载链接短时有效。

## 验收条件
正确模板可新增/更新商品；预览能展示影响和重复/冲突；执行策略明确选择部分有效行或整批原子模式；错误字段清楚指明行列；失败/中断可安全续跑且不污染无效数据；库存导入形成可审计的调整流水；远程图片导入限制通过验证；导出符合权限并在到期后不可继续下载。

## 依赖
M00、M03、M12（库存导入）、M15（安全导出/文件过期）、媒体策略。

## 项目实施建议
第 D/F 阶段；估算 6–9 人日。
