# EZSTARTCommerce 需求处理决议

> 状态：产品负责人建议基线，供本项目文档、估算、原型和开发范围统一使用。客户专属参数须在该客户需求冻结和上线前确认；不将未确认的第三方服务或经营规则写死在核心代码中。

## 1. 会员系统范围

- 会员能力纳入通用核心和后台，不再只做顾客标签。
- 包含后台会员档案、订单关联、等级、积分流水、积分规则、权益/会员价配置、优惠券关联、营销同意记录和审计。
- 顾客可以自愿用经验证的邮箱/手机一次性验证码登录会员中心；不使用密码，购物和结账不强制注册或登录。
- 首期会员中心展示等级、积分、优惠券、订单摘要和会员资料；不做移动 App、跨店积分、复杂营销自动化。
- 访客与会员订单不得仅按姓名自动合并。会员关联需已验证联系方式或由后台人员审查。
- 验证渠道通过通知适配器接入。邮件验证码作为基础实现；短信验证码需商家提供获准的短信服务账户和模板。
- 积分发放时点、退款扣回、过期、兑换比例、升降级和优惠叠加按商家后台规则配置，并有逐项审计。

## 2. 页面状态与流程覆盖

客户前台验收必须覆盖正常流程和可恢复状态，而不只验收静态页面：

- 商品列表：加载、空分类、搜索无结果、筛选无结果、服务失败、缺图、缺货/下架。
- 购物袋：空袋、优惠码无效/过期/未达门槛、库存或价格变化、会话过期。
- 结账：字段错误、不可配送、库存变化、重复提交、服务暂时失败。
- 付款/订单：COD 待收款、待确认、线上付款中、成功、失败、回调延迟、订单已建立但通知失败。
- 会员：验证码发送中/成功/过期/错误/限流、首次加入、已有会员登录、无会员账户、资料缺项、积分与优惠为空。
- 订单查询/售后：验证失败或过期、订单不可查询、申请已提交、审核中、退款处理中/成功/失败。
- 全站：404、维护、网络中断和可重试错误；错误提示不泄露订单或顾客是否存在。

## 3. 交易与客户参数

**核心默认能力：**单商家独立站；COD；一个线上信用卡/支付服务适配器；单币种交易；可配置配送区域、固定/按金额运费、免运门槛和基础税费展示；人工履约字段；服务端校验价格、库存、优惠和最终金额。

**逐客户配置，不能由模板方擅自代填：**首发国家/地区、商品可售范围、年龄/资格条件、商户支付服务商与生产账户、COD 区域/上限/收款确认、币种、税费口径、配送地区/价格/免运门槛、退换货和退款规则、通知服务商。首期不默认承诺多币种结算、税务引擎或承运商轨迹接口。

具体参数由 CLIENT_LAUNCH_INPUTS.md 按客户填写；未获商家书面确认和必要服务商审批，不启用生产交易。

## 4. 私有部署与运营责任

- 默认交付方式：客户拥有自己的云账号/项目和域名；开发/交付方在授权下安装并初始化独立实例，之后交接账号、部署说明和恢复手册。
- 每客户独立应用、数据库、媒体、密钥、备份和发布记录。一个商家多站点按多实例处理。
- 基础交付包括部署、HTTPS、健康检查、备份配置、上线前恢复演练和版本交接。
- 生产监控值守、代托管、持续升级、故障响应时限和数据恢复协助需另签维护/SLA；开发方不默认持续持有客户生产凭证。
- 如客户要求代托管，仍使用独立实例，主机、备份、监控、支持和退出迁移费用另列。

## 5. 客户专属前台范围

- 通用核心提供可复用 API 和演示参考前台；每位客户签署独立站点地图、页面/状态清单、桌面/手机稿、三语内容责任、外部集成清单及验收条件。
- 每客户基础候选页面：主页、分类、搜索、商品详情、购物袋、结账、订单结果、政策/内容、会员验证码入口、会员中心、订单查询、售后入口、资格提示（经审核后启用）、404/维护。
- 每页同时列出正常、空、错误、不可售/不可用等状态。购买主流程与交易规则由核心 API 约束，不能由定制前端自行改价或宣告付款成功。
- 客户确认页面清单和高保真设计后再报价。增加页面、动效、特殊商品配置器、定制交互、第三方集成或翻译内容均走变更估算。
- 参考网站仅作为功能/体验参考；不假定有源码、图片授权、后台权限或旧数据。

### 5.1 参考站（客户指定）

**萬鋒行 · smwfhk.com**（香港免稅香煙網購，WordPress + WooCommerce + LiteSpeed）。
客户确认以该站的**信息架构与选购体验**作为参考基准。

可取用的部分（只做交互与 IA 参考）：

| 参考站做法 | 对本站的价值 |
|---|---|
| 品牌即一级分类（Marlboro / MEVIUS / 中華 / ESSE… 30+ 品牌入口） | 烟草品类用户按品牌找货，比按品类更快 |
| 加熱煙单列（IQOS 主機 / TEREA 煙彈 / Ploom 分開） | 主機与耗材是不同购买决策，混在一起会误导 |
| 商品以「包 / 條」计价，卡片直出单价 | 与该市场用户的价格预期一致 |
| 结账只保留貨到付款 + 現金交收 | 与本项目「全店线下收款」的结论一致 |
| 页脚与商品页常驻 WhatsApp 咨询入口 | 香港烟酒零售的隐形客服主渠道 |

**不取用的部分**（明确排除，不作为本项目的对标项）：

- 无年龄门禁、无市场资格审核 —— 属合规缺失，本站保留「资格提示 + 审核后启用」。
- `Compare` 对比、强制 `Login / Register` —— 本站坚持访客结账优先。
- 商品文案与图片 —— 仅作结构参考，不复制其文案、图片与商品库。

## 7. SEO 与个人资料请求基线

- SEO/URL 管理属于后台内容运营基线：按语言维护标题、描述和索引开关；系统生成 canonical/alternate、Sitemap 与 robots；已发布 slug 变更需做 301，并阻止冲突/循环。客户前台必须让主要落地页元数据可被搜索引擎读取。
- 个人资料访问/导出、更正、营销退订和删除/匿名化由后台请求队列管理；处理前按客户确认的方法核验身份并授权，营销退订立即生效；交易记录按客户确认的保留规则单独处理；导出限时，处理过程留审计。
- 每位客户仍需提供目标域名/旧 URL、索引偏好、隐私联系人、数据保留期、请求处理时限、身份核验方式和可批准的保留例外。平台提供执行能力，不代替客户或专业顾问作市场合规判断。
