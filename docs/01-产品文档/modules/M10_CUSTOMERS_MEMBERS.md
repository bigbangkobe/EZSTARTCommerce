# M10 顾客与会员

**优先级：**P0  
**估算状态：**需按本范围重估；原 7–11 人日仅覆盖 CRM，不覆盖 OTP 登录、会员中心和积分/等级。

## 产品目标
后台完整管理顾客与会员运营；顾客不必注册即可购物和结账，会员可自愿用一次性验证码查看账户权益。

## 首期范围
- 后台顾客列表、资料查看/编辑、订单关联、标签、备注、营销同意、受控搜索/导出。
- 顾客资料请求处理：经身份核验后受理访问/导出、更正、删除/匿名化请求；营销退订可通过已验证的退订链接或已登录偏好设置立即生效。管理员按角色审核、处理并记录结果。首期为后台受理工作流，不默认承诺顾客自助隐私门户。
- 会员档案和会员号；等级、成长值/消费累计、积分规则、积分账户与不可改写流水。
- 积分获取、兑换、过期、订单取消/退款扣回；处理需幂等、有来源订单和操作审计。
- 会员价格/权益配置、优惠券关联、等级有效期/升级与降级规则。
- 顾客端邮箱 OTP 会员验证与中心：资料、等级、积分、优惠券、订单摘要；不设密码。
- 访客结账仍然不要求登录。没有可用验证渠道或 OTP 服务失败时，顾客可继续访客购买。
- 手机短信 OTP 依赖客户选择并提供获批的短信服务商账户；邮件 OTP 是基础实现。
- 营销同意与交易通知分开记录；验证码不得被当作营销授权。

## 不纳入首期
密码认证、强制登录结账、跨商家账户/积分、移动 App、复杂会员营销自动化、自定义代码脚本。顾客自助售后是否纳入由售后模块范围决定。

## 主要数据对象
Customer、MemberProfile、MembershipTier、PointAccount、PointLedger、MemberBenefit、OtpChallenge、ConsentRecord、CustomerTag、CustomerNote、OrderMemberLink。OTP 只存验证码摘要/挑战状态，不保存明文码；会员登录会话安全存储并限时。

## 关键业务规则
- 电话/邮箱必须验证后才可关联或登录会员；不能只凭姓名自动合并。
- 访问/导出、更正、删除或匿名化前须核验申请人身份，不得向未经核验的请求人泄露是否存在对应账户。营销退订使用已验证的单次令牌/已登录上下文，立即停止后续营销，不等待其他请求审批。访问/导出文件短时有效、受权限控制并记访问审计。
- 删除请求不得自动改写订单/支付/售后等历史交易事实；按业主批准的保留规则分别删除或匿名化可处置的会员/营销资料，并记录保留例外、依据版本、处理者和完成时间。拒绝/延期须记录原因并由客户负责提供合法依据与对客文案。
- 订单完成后发放积分；取消/退款按已确认比例幂等扣回。兑换占用、撤销和优惠券状态必须可追踪。
- 会员等级和积分有效期由店铺配置；规则变更只影响未来计算，历史流水保留原规则版本。
- 达到 OTP 限速或失败上限时暂时阻止重试；通用错误文案不暴露账户是否存在。
- 退款、积分人工调整、导出和等级变更按角色授权并留原因/审计。
- 不在分析事件和应用日志中记录完整邮箱、电话、OTP 或会员敏感字段。

## 页面与状态
后台：顾客档案、会员列表、等级规则、积分规则、积分流水、同意记录。
隐私请求状态：received → identity_verification_pending → under_review → approved / rejected / needs_information → processing → completed；处理超期/客户保留例外需显示负责人和原因。
前台：验证码登录/首次加入、会员中心、积分/优惠/订单空态。
OTP 状态：可发送、发送中、已发送、验证错误、过期、限流、服务不可用。中心状态：无积分、无优惠券、无订单、资料待完善。

## 验收条件
- 顾客可不登录从浏览到下单；会员可用已验证邮箱 OTP 登录并查看自己的会员资料。
- OTP 过期、重复使用、暴力尝试和账户枚举受到限制。
- 订单、积分、退款、兑换和会员级别变更可追溯；重复事件不会重复发放/扣回。
- 访客资料不会仅按姓名关联；营销同意有来源、用途、时间和撤回记录。
- 未核验身份的资料请求不得导出/删除；顾客访问/导出请求、营销退订、更正和删除/匿名化结果按状态记录，订单等需保留的交易事实不被误删；导出链接过期后不可使用。
- 请求队列按客户配置的到期时间提醒负责人；超期项显示逾期时长、负责人和延期/升级说明，不得静默变成已完成。
- 无通知服务或会员登录故障时不阻断访客结账。

## 依赖与估算
依赖 M00 身份/审计、M07 订单、M08 付款/退款事件及 M13 邮件/短信适配。访客结账不依赖会员；M11 会员专属优惠通过会员身份与优惠资格契约联调，不阻断 CRM、OTP 或基础会员资料交付。开发前选定 OTP 渠道并重新估算。
