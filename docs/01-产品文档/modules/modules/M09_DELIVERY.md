# M09 配送与运费规则

**优先级：**P0  
**初步开发估算：**5–8 人日（加入分批发货与订单地址变更校验后需重新估算）

## 产品目标
让商家按店铺/市场配置配送区域、运费、免运规则和预计时效。

## 首期范围
配送区域；按地区固定收费或按订单金额门槛；免运规则；预计时效说明；后台订单配送备注和状态。初期支持人工履约，支持录入一个或多个包裹及各包裹商品数量、承运商和追踪号；不含承运商 API 自动下单/轨迹聚合。已补承运商签名 webhook 状态回传（in_transit/out_for_delivery/delivered/exception/returned）：先验签、按 eventId 幂等、只认已 dispatch 包裹，delivered 由服务端推进履约且不改付款状态。

## 主要数据对象
ShippingZone；ShippingMethod；ShippingRate；FreeShippingRule；ShipmentRecord（承运商、追踪号、状态、时间）。

## 关键业务规则
结账时根据地址选择唯一有效规则，向顾客显示费用构成并在订单保存费用快照；暂不提供自动物流 API/轨迹聚合；市场限制以审批后的可配送区域为准。分批发货的商品数量合计不得超过订单数量，已发包裹不可被普通订单编辑覆盖；地址只能在未发货时经授权修改并重新校验区域/运费。

## 验收条件
后台能设置、排序、启停区域和费率；测试地址能得到预期运费；不可配送地址不能提交订单；订单保存费率快照。后台可创建/更新包裹追踪信息并查看每包商品数量；地址变更符合 M07 权限、区域和金额校验；未集成物流商时仍可人工完成发货闭环。

## 依赖
M01、M07。M06 在结账流程调用配送费率报价契约；配送规则可独立配置和验证。

## 项目实施建议
第 E 阶段配置，后续履约关联；估算 5–8 人日。
