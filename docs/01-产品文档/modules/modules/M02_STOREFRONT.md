# M02 前台主题与店铺体验

**优先级：**P0  
**初步开发估算：**10–14 人日（基础参考前台；不含客户专属设计/开发）

## 产品目标
提供一套可运行的移动端友好参考前台，并定义客户专属前台通过稳定电商 API 接入的方式。客户可以要求不同页面结构、视觉和购物交互，需按页面清单单独定制开发。

## 首期范围
基础参考页包含首页、导航、分类、搜索结果、商品卡片、商品详情、购物车入口、语言切换、页脚和客服入口；响应式布局、基础主题配置及 SEO。客户定制按其批准的站点地图、视觉稿和流程另建前端实现，不限于换色/换标志。SEO 技术基线涵盖已发布页面/商品的可索引元数据、每语言 canonical/alternate URL、XML sitemap、robots 与 404/重定向；商品/分类等主要落地页元数据需在初始 HTML 或可被搜索引擎正常获取的渲染输出中可见，不能只在浏览器端异步插入。

## 主要数据对象
ThemeConfig；NavigationItem；HomepageSection；StorefrontPreference；SEOFields；StorefrontBuild/ClientFrontendVersion；APIContractVersion；与商品、分类、内容页关联。

## 关键业务规则
每个客户前端以主题/组件注册表声明可由后台配置的区块与字段；商家可在后台编辑该范围内的内容、选择商品及调整区块/商品顺序，发布后前台同步读取。客户特有页面结构、交互和未注册的专属组件按项目开发，不提供任意代码或任意拖拽式页面构建器。每个客户前端独立验收/发布；行业图文、广告和销售内容由客户审核。

## 验收条件
基础参考前台主要流程可用；商家发布后台内容/陈列配置后，桌面与手机前台均展示对应已发布版本，草稿不公开；商品排序和区块排序按配置生效；客户前台按已批准页面清单、视觉稿、语言和响应式标准验收；客户发布不影响其他客户；API 版本兼容关系可追踪。生产站点具有正确的 canonical/hreflang、XML sitemap 和 robots 输出；预览、管理页、购物袋/结账个人化页面不会被公开索引；slug 更新保留已批准重定向且不产生循环；主要语言页面可被搜索引擎读取正确标题/描述。

## 依赖
设计系统、M01 语言/店铺配置、M03 商品目录及稳定 API 契约。CMS 内容由前台按发布契约读取；基础前台外壳和预览契约可先于 M04 完成。客户专属设计/开发范围另行冻结。

## 项目实施建议
第 B 阶段完成参考设计和首个客户页面发现；第 D 阶段交付基础参考前台。每个客户的视觉设计和定制开发单独估算，依据页面数量、流程和接口复杂度报价。
