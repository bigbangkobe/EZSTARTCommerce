# 商业分层与报价模型

> 状态：设计基线 v0.1（待评审，具体数值由业务确认）
> 定位：把"定制方式"转成清晰的商业分层，让 A 类配置级成为可规模化的标准产品，B/C 类作为增值服务。
> 关联：[定制模型](CUSTOMIZATION_MODEL.md) · [重做方案](../06-产品设计逻辑/03-配置化前台与交付体系重做方案.md)

## 1. 分层模型

| 层级 | 定义 | 客户得到什么 | 交付方式 | 报价 |
|---|---|---|---|---|
| **A 配置级（默认）** | 用配置即可满足 | 专属品牌前台、首页区块编排、三语文案、模块开关 | 填配置 → 标准部署 → 上线 | 标准价（固定） |
| **B 视觉级（例外）** | 需新设计系统/组件样式 | A 类 + 独特视觉主题包 | 配置 + 主题包开发 | 另计 |
| **C 工程级（例外）** | 需新页面/流程/深度集成 | B 类 + 独立前端工程 | 独立开发 | 另计 |

核心：**A 类是产品、是默认值；B/C 是服务项目、是例外。** 判定流程见 [定制模型](CUSTOMIZATION_MODEL.md) 第 2 节。

## 2. 收入结构

| 项目 | 类型 | 说明 |
|---|---|---|
| 底座授权 | 一次性/授权 | 通用核心 + 后台 + 配置引擎的使用权 |
| 标准部署 | 每实例 | 一键起实例、初始化、冒烟、交付清单 |
| A 类配置 | 标准 | 填配置、校验、验收；固定价，边际成本趋近于零 |
| B/C 类定制 | 增值 | 按页面/交互/接口复杂度单独估算 |
| 持续维护升级 | 年费 | 版本升级、安全更新、值守、SLA（分级） |
| 代托管（可选） | 年费 | 每客户隔离环境的主机/备份/监控，按服务等级计价 |

第三方费用（主机、域名、支付手续费、短信/邮件）分列代收，不计入产品收入。

## 3. 报价分层示例（结构示意，数值待业务填）

```
标准客户（A 类）
  底座授权        [固定]
  标准部署        [固定/实例]
  A 类配置        [固定]
  维护升级(年)     [固定/等级]
  ────────────────────────
  小计            —— 可规模化、可预测

例外客户（B/C 类）
  标准客户小计    [同上]
  + 定制开发      [按人日 × 复杂度]
  + 内容/翻译     [按量]
  ────────────────────────
  小计            —— 项目制、单独报价
```

## 4. 商业意义

- **从做项目到卖产品**：A 类边际成本趋近于零，客户数与团队规模解耦。
- **可预测交付**：A 类固定价 + 标准周期，客户体验一致，销售可复制。
- **升级收入可持续**：配置与代码分离后，底座升级可安全批量推送，年费有交付基础。
- **例外透明计价**：B/C 单独报价，避免"标准产品里塞定制"导致的成本失控。

## 5. 关键度量（支撑商业决策）

- A 类配置级交付占比（目标 ≥ 80%，由团队确认）。
- 标准客户从签约到上线的周期。
- 单客户交付人力（A 类应显著低于 B/C）。
- 年费续费率与升级推送成功率。

> 本模型为产品设计参考，具体数值与合同条款请结合公司商业与法务要求确认。
