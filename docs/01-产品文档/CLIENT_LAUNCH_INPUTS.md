# EZSTARTCommerce 客户上线参数表（实例配置源）

每个客户/独立实例在需求冻结时填写一份。空白项表示需要客户或专业顾问确认，不代表系统默认接受。交易相关未完成项不可带入生产上线。

> 重做说明：本表已从「人工核对清单」升级为「机器可读实例配置源」的输入界面——一次填写同时驱动部署参数、前台主题与业务规则，避免重复录入。配置的文件格式、schema 与校验规则见 [实例配置规范](INSTANCE_CONFIG_SPEC.md)。下表保留为面向客户/顾问的填写视图。

## A. 已确定的模板基线

| 项目 | 基线 |
|---|---|
| 项目模式 | 通用电商核心 + 配置驱动前台（A 类为默认） + 每店独立私有部署 |
| 首期场景 | 烟草为首个行业案例；不将品类/地区限制写死在通用核心 |
| 语言 | 简体中文、繁体中文、英文；客户提供最终翻译 |
| 交易身份 | 访客可直接结账；会员中心可选用邮箱验证码登录，不强制注册、不设密码 |
| 会员 | 后台档案、等级、积分、权益、优惠券关联和同意记录；规则由客户确定 |
| 支付 | COD + 一个获批的线上支付服务适配器；生产商户账户由客户提供并获批 |
| 配送 | 核心支持后台配置的配送区域与费率；首期默认人工履约，不含物流轨迹 API |
| 部署 | 客户云账号内独立实例，交付方授权安装；持续代运维另行约定 |
| 定制前台 | A 类配置级为默认（填配置即可，标准报价）；B/C 类例外另行签署页面清单、稿件、状态、接口和验收范围 |
