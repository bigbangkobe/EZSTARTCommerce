### 4.9 生产发布记录（2026-11-21）前台商店骨架改版

三连发：`27b222e`（前台骨架改版）→ `d95c46b`（目录页改请求时渲染）→ `3e26844`（购物袋空态）。
每次 `deploy.sh` 30 秒左右，**无迁移**（仍 38 条），冒烟 200。

改这一版的原因：前台只有一个「海报式」首页——hero 占满一屏、没有任何分类入口、商品缩略图是
一块灰色方块写着「商品圖片」，客人从首页到某个商品要走三层。后台已经能上架了，前台却没有
让人「逛」的结构。

| 阶段 | 事实 |
|---|---|
| 回滚点 | `:prev` 三次重打，当前指向 `27b222e` 镜像 |
| 迁移 | 无新迁移，仍 38 条 |
| 页面 | `/zh-HK` `/zh-HK/products` `/zh-HK/products/demo-matcha-bowl` `/zh-HK/categories` `/zh-HK/cart` 全部 200 |
| 视口 | 1440 / 1180 / 390 三档截图；`scrollWidth === clientWidth`（无横向溢出） |
| 渲染 | 首页、商品列表、分类列表改 `force-dynamic` |

结构调整：
- **页头三段**：工具条（语言/会员/购物袋）→ 品牌条（印章 + 店名 + 主导航 + WhatsApp）→ 分类条
  （横向滚动）。分类条是关键：客人靠分类找货，只藏在 `/categories` 里等于没有导航；
  窄屏主导航收起时，分类条就是唯一导航。
- **首页重排**：hero 双栏（左文案右「一期一会」卡 + 在售件数）、分类磁贴、商品栅格、
  服务承诺、关于。区块序号不再写死「壱弐参」，按主题实际区块数计算。
- **商品卡**：图像优先（无图用「名称首字 + 由名称推导的色相」占位，比灰底字更有辨识度），
  价格与「查看详情」压到底部一行；卡片 hover 只抬起 4px，不做放大镜式的夸张位移。
- **商品详情**：面包屑 + 左粘性大图 + 右规格表，规格表把「规格 / 价格 / 库存」对齐成三列。
- **页脚**：四栏（品牌＋简介、选购、客户服务、联络），WhatsApp 改右下角常驻圆钮。
- **文案**：三语字典补 `shell` 段，缺译仍是编译错误（`Copy` 由繁体推导）。

同时修掉两个既有缺陷（不是这次改版引入的）：
- 首页/商品页在**构建镜像时**预渲染，那时 API 还没起，部署后首屏会显示「商品暂时无法载入」，
  要等一次 ISR 才恢复；改为按请求渲染。
- 购物袋在「还没建过袋」时 `GET /storefront/cart` 返回 401，页面把 `cart === null` 当成加载中，
  访客看到永远转不完的提示；改为区分「已加载」与「有袋」。

已知未做：
- 分类还没有 `slug`（后台「商品 → 分类」里没填），前台按规则不列出无 slug 的分类，
  所以分类磁贴与分类条目前只有「全部分类」。补上 slug 即自动出现，无需改代码。
- 商品详情页仍无真实图片位（`media` 为空）；上传图片后走 `product.image` 分支。
