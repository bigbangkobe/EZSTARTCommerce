# EZSTARTCommerce 私有部署模式

## 1. 已确认的产品模式

EZSTARTCommerce 是一套可复用电商模板，面向多个商家分别私有部署。每家商家可配置和运营自己的品牌独立站，售卖自己的商品，并通过独立后台管理经营资料。

本项目不采用共享多商户 SaaS：各商家不共用商品库、订单库、顾客资料、支付凭证、管理账号或经营报表。

## 2. 推荐实例模型

**一位商家 + 一个独立站 = 一个独立实例**，默认包含：

- 一个商家品牌和域名。
- 一套顾客前台与管理后台。
- 一套独立数据库和媒体文件空间。
- 一套独立管理员/店员账号。
- 一组独立支付、通知和物流服务凭证。
- 独立备份、发布和故障恢复记录。

若同一商家经营多个品牌或网站，建议首期为每个站点部署一个实例。多站点共用后台可另行设计。

## 3. 商家每个站点可自行配置

- 站点名称、标志、主题颜色、首页内容和域名。
- 启用语言、默认语言、货币、时区和目标市场。
- 自己的商品、商品分类、规格、价格、库存和图片。
- 配送区域、运费、免运规则和预计时效。
- 货到付款及获批的线上支付方式。
- 优惠券、会员客户资料、客服联系方式和通知模板。
- 页面、FAQ、政策说明和资讯文章。
- 前台品牌、配色、字体、首页区块编排、文案由实例配置生成，换客户无需前端开发（A 类默认）；独特页面/交互按 B/C 类例外定制。
- 交付工具链：标准部署包 + 一键起实例 + 批量升级脚本，配置与代码分离，升级不覆盖客户配置（见 [交付工具链规范](../01-产品文档/DELIVERY_TOOLCHAIN_SPEC.md)）。

## 4. 私有部署开通流程

1. 填写并校验实例配置（Instance Manifest），确认上线阻断项已签字（见 [实例配置规范](../01-产品文档/INSTANCE_CONFIG_SPEC.md)）。
2. 默认在商家持有的云账号内，用标准部署包 + 一键脚本拉起独立环境；交付方获得限时授权完成初始化。代托管独立实例另签维护/SLA。
3. 脚本自动完成：生成环境变量、初始化数据库（StoreConfig/ThemeConfig）、配置域名、DNS、HTTPS/SSL、主机区域及备份。
4. 前台由实例配置生成品牌/区块/文案，无需前端开发；B/C 类例外按批准范围单独开发。
5. 商家上传/导入自己的商品并确认前台展示。
6. 使用测试订单验证前台、付款、配送、库存、通知和后台流程。
7. 按获批市场完成业务审查后再启用生产交易。
8. 后续用批量升级工具按版本升级；升级前备份并验证 API 兼容，可一键回滚。

## 5. 必须明确的隔离要求

- 实例间数据库、媒体文件、用户账号、密钥、日志权限和备份隔离。
- 分析数据只属于对应商家，不向模板方集中汇总，除非商家明确授权。
- 不用一套共享的管理员账号管理所有商家店铺。
- 客户支持访问商家环境应获得授权，尽可能限时并记录。
- 任何实例迁移、恢复或删除操作都需确认目标商家和实例编号。

## 6. 默认服务方式与可选服务

“私有部署”确定了商家实例隔离，但谁负责主机与更新还需在以下选项中选择：

- **标准交付：**商家拥有云账号；交付方在获准时间窗内部署，配置备份/健康检查并交付恢复与升级文档。
- **代托管独立实例：**交付方运行每客户隔离环境；主机、备份、监控、故障响应、退出和迁移费用按服务等级单独计价。
- 是否提供持续升级、值守和恢复支持，以及响应时间、支持时段和数据恢复目标，写入客户服务协议。

## 7. 本项目不包含的共享平台功能

- 商家自助注册并在线创建实例的中央控制台。
- 统一的跨商家订单/顾客/销售总览。
- 按月订阅、自动扣费和配额账单系统。
- 一个后台切换管理多个商家店铺。
- 未经商家授权的跨店分析或数据共享。

本项目范围固定为逐客户独立部署；以上共享平台功能不是本项目交付内容，若未来另有需求再单独立项评估。
