# 顾客前台页面设计

## 1. 设计边界

每家客户拥有独立前台。以下页面是购买流程基线，客户页面清单允许增删；商品、库存、价格、优惠、配送、付款和订单数据来自该客户独立后台 API。顾客可访客购物/结账，不强制注册。会员可自愿通过一次性验证码登录会员中心，不使用密码。前台不能自行裁定库存、应付金额或付款成功。

示例品牌、文案、产品和币种是占位，实际站点需按客户设计稿和目标市场确认。

## 2. 全局框架

- 顶部公告：配送提示、店铺公告或维护状态。
- 主导航：品牌标志、搜索、语言切换、购物袋；分类和内容导航由后台维护。
- 页面内容：按客户视觉开发，标题、商品信息、价格和购买动作优先。
- 页脚：客服、配送/付款/退换说明、隐私政策和服务条款。
- 移动端：导航抽屉，内容单列，订单摘要折叠；加购/继续结账动作不遮挡字段或错误提示。
- 语言：简体中文、繁体中文、英文；地区、日期、数字、币种按实例配置呈现。
- 适用市场/年龄门槛：是否启用、何时拦截必须按客户目标市场评审；前端提示不能替代服务端校验。

## 3. 页面索引

| ID | 路由样例 | 页面 | 主操作 |
|---|---|---|---|
| F01 | / | 首页 | 进入精选、分类或搜索 |
| F02 | /collections/{slug} | 分类列表 | 筛选、排序、打开商品 |
| F03 | /search?q= | 搜索结果 | 修改关键词、选择商品 |
| F04 | /products/{slug} | 商品详情 | 选规格并加入购物袋 |
| F05 | /cart | 购物袋 | 修改数量、用优惠码、去结账 |
| F06 | /checkout | 访客结账 | 填资料、选配送/付款、确认下单 |
| F07 | /order/{result} | 订单结果 | 查看状态与下一步 |
| F08 | /pages/{slug} | 内容页 | 阅读政策、FAQ、品牌资料 |
| F09 | /eligibility | 资格提示（条件启用） | 确认或退出 |
| F10 | 404 / 5xx | 错误/维护页 | 返回、搜索或重试 |
| F11 | /orders/lookup | 访客订单查询（可选） | 安全验证后查看最少订单状态 |
| F12 | /orders/{token}/support | 售后申请（按客户范围） | 对已验证订单提交售后请求 |
| F13 | /account/verify、/account | 会员验证与中心 | 邮箱 OTP 登录、查看等级/积分/优惠/订单摘要 |

## 4. F01 首页

### 布局顺序
公告条；品牌头部；分类导航；主视觉和一个明确主按钮；精选分类；精选商品；可配置活动/品牌内容；配送付款提示；页脚。

### 行为
- 分类进入 F02，商品进入 F04，搜索进入 F03。
- 首页模块顺序、内容、图片和商品精选由后台配置；特殊模块结构与互动由该客户前端开发。
- 未配置的模块隐藏，不显示空白框或后台字段名。
- 停业/维护状态不展示可直接下单的购买动作。

### 状态/数据
读取已发布模块、商品、导航和多语言内容；记录首页访问、分类点击、商品打开。商品缺图显示占位并在后台提示补齐。

## 5. F02 分类与 F03 搜索

### 共同布局
面包屑、标题和说明；支持的分类/属性筛选；排序；结果数；商品网格；分页/加载更多；底部 SEO 内容。搜索页回显搜索词，可继续修改。

### 行为
- 筛选组合后更新结果；显示已选条件和清除入口；变化后回到第一页。
- 排序至少支持推荐、新品、价格升降；销量排序需先确认口径。
- 搜索为空时提供精选分类；无结果时保留关键词并允许清除筛选。
- 服务超时可重试，不能丢失搜索词。下架、缺货、区域不可售商品不允许加购。
- 筛选项依据后台商品属性配置，不显示没有数据的空筛选。

### 数据/事件
读取商品分页、分类、翻译、价格和可售摘要。事件包括 search_submit、search_no_results、category_view、filter_apply、sort_change、view_item；不采集个人资料。

## 6. F04 商品详情

### 信息层级
面包屑；商品图和替代文本；名称、SKU/规格、价格/促销条件；库存状态；规格选择和数量；加购；详情/参数/配送退换政策；有数据时显示相关商品。

### 规则
- 规格组合改变时更新图片、SKU、价格和库存；无效组合不可选。
- 加购时服务端再次核价、校验库存和可售区域；购物车显示价格不能作为订单依据。
- 缺货、下架、受限商品说明当前状态，隐藏无效购买动作。
- 促销资格和期限由服务端返回，不使用误导性原价展示。
- 成功加购后更新购物袋数量并提示；失败时在规格或数量附近说明原因。

### 事件
view_item、select_variant、add_to_cart、add_to_cart_error。商品信息来自后台多语言目录与对应 SKU。

## 7. F05 购物袋

### 页面结构
商品行（图片、名称、规格、单价、数量、行总价、移除）；优惠码及结果；小计、折扣、预估配送费、适用税额、最终金额；继续购物和去结账。

### 状态与规则
- 修改数量后服务端重新确认库存、价格和折扣，并明确提示金额变化。
- 无商品时提供回到分类入口；优惠码区分无效、过期、未达门槛和不适用。
- 配送费尚未确定时标明“预估”，结账时显示最终金额。
- 会话过期时解释原因并提供恢复/重新加入入口。
- 记录 view_cart、update_cart_item、remove_cart_item、apply_coupon、begin_checkout；分析不记录优惠码明文。

## 8. F06 访客结账

### 页面分段
联系信息 -> 配送地址和方式 -> 已启用付款方式 -> 订单复核 -> 提交订单。单页或多步布局由客户前台定制，但必须保留最终复核和明确的总金额。

### 校验
- 必填信息最少化，格式检查不过度拒绝合法电话或地址。
- 不支持的地区或配送方式说明原因，不创建可履约订单。
- 结账期间价格或库存变化，展示差异并要求顾客确认。
- 货到付款和获批线上支付分别显示付款说明；不存在的方式不显示。
- 订单提交有幂等保护，重复点击不能创建重复订单。
- 输入错误定位到字段并保留其他输入；API 暂时失败提供重试。
- 事件 checkout_step_view、checkout_validation_error、payment_method_select、purchase_attempt 不带联系方式。

## 9. F07 订单结果

支持订单待确认、待付款、已付款、付款失败、付款处理中等服务端状态。

- 货到付款显示待确认/待履约，不显示已付款。
- 线上支付是否成功以服务端回调确认，不能依靠浏览器跳转参数。
- 付款处理中提供安全刷新/稍后查看说明；失败时提供继续付款或联系商家的路径。
- 订单已建立后通知失败不改变订单状态。
- 如需顾客查询订单，必须另行确认查询凭证；不能只凭可猜订单号暴露个人地址和电话。

## 10. F08 内容页、F09 资格提示、F10 错误页

### 内容页
用于品牌介绍、FAQ、配送/付款说明、隐私与条款。后台维护文本、图片、多语言、SEO 和草稿/发布版本；客户前端定义页面布局。政策页面显示版本或更新时间。

### 资格/市场提示
只在目标市场审核要求确认后启用。提示文案可配置；未满足规则时前端提示并由 API 同步拒绝商品展示或下单。单纯前端弹窗不能作为合规或交易授权保障。规则未确认时保持待定。

### 错误/维护
404 提供首页、搜索和分类入口；维护页不泄露内部错误；商品不可售不保留有效加购按钮；付款状态未知显示确认中。错误信息可有支持编号，服务日志通过请求 ID 关联并脱敏。

## 11. 前台验收

- 每页检查三语、移动端、键盘操作、加载/空态/错误/服务端拒绝状态。
- 商品价格、库存、优惠、配送和付款状态与服务端一致。
- 图片有替代文本；表单错误与字段关联；颜色不是唯一状态提示。
- 顾客个人资料不进入分析事件。
- 页面配置和客户专属代码边界有记录，可按批准的页面清单验收。


## 12. F11 访客订单查询（可选）

入口为订单通知中的短期安全链接，或订单号加一次性验证。订单号本身不能作为身份凭证。成功验证后显示订单号、商品摘要、付款/履约状态、物流信息和售后入口；地址、完整电话、内部备注和支付凭证继续隐藏。错误提示不透露订单是否存在；验证码需限速、过期且不可重用。没有邮件/短信验证渠道时隐藏自助查询并提供客服入口。

## 13. F12 售后申请

从已验证订单进入，选择订单商品/数量、取消/退款咨询/退货/换货类型和原因。页面明确这是“申请”，不是退款承诺；服务端校验订单状态、数量、商品资格和政策时间。提交后返回案件号和后续状态通知方式。没有已配置身份验证时由客服从后台创建。详见 AFTERSALES.md。
## 14. F13 会员验证码入口与会员中心

### 登录入口
- 输入邮箱并请求一次性验证码；短信渠道只有在客户配置短信服务商后启用。
- 不设置密码；验证码设置有效期、单次使用、限速和失败锁定。
- 错误文案不泄露该邮箱是否已注册；新顾客可在验证后自愿加入会员。
- 结账始终提供访客选项，会员登录不可成为购买前置条件。

### 会员中心
显示会员等级、升级进度、积分余额与到期提示、可用优惠券、近期订单摘要、积分流水和资料设置。
无订单、无积分、无优惠券、资料待补充、验证码失效或通知服务故障均有独立状态。
会员中心数据通过已验证会话鉴权；不得将邮箱或 OTP 写入分析事件。

### 权益和交易关联
优惠、积分兑换和会员价均由服务端复核；前端展示不构成价格承诺。
访客下单只有在顾客主动验证会员身份或后台人工审查后才关联，不按姓名自动合并。
积分依照已配置订单完成节点发放；取消/退款按规则冲回并记录来源订单和规则版本。
