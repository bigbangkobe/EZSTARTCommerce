# 商家后台页面与模块设计

## 1. 后台定位和信息架构

商家后台服务一家已独立部署的店。后台可有多名员工，但一个客户不能看到另一个客户的商品、订单或数据。前台结构由客户前端项目实现；后台负责编辑其数据和内容，不提供首期任意拖拽建站器。

### 主导航

- 工作台：总览。
- 商品：商品、分类、品牌、规格属性、导入/导出。
- 订单：订单列表、订单详情、付款/配送记录。
- 售后：售后案件、退款审批、退货质检和换货跟踪。
- 顾客：顾客/会员资料、隐私请求处理队列。
- 促销：优惠券、发放/核销。
- 库存：库存总览、流水、预警。
- 内容：页面内容、FAQ/公告、导航、语言、SEO 元数据和 URL 重定向。
- 交易设置：付款、配送、通知。
- 数据统计：经营报表、网站分析。
- 店铺设置：品牌、市场、语言、员工权限。
- 系统运营 M15：独立的部署/运维职责区，不默认出现在普通商家后台。

全局顶栏包含当前商店身份、快速搜索、语言、通知入口和用户菜单。每个实例只显示一个当前店铺，不提供跨店切换。

## 3. 后台共用页面模式

### 列表页

标题和说明 -> 主操作 -> 搜索/筛选 -> 结果计数 -> 表格 -> 分页。筛选项只出现用户能查看的字段；列表选择行时出现批量动作。批量危险动作再次显示对象数和影响范围。空态提供单一相关操作，不将“无记录”误写成加载失败。

### 编辑页

标题、对象状态、保存/返回 -> 分组字段 -> 右侧或底部预览/保存状态。表单保存期间禁用重复提交；保存失败保留用户输入；离开未保存页面提醒。需要发布流程的对象采用草稿、预览、发布、归档状态。

### 详情页

顶部显示识别信息与当前状态；下方按时间线排列状态、付款、履约、通知和操作记录。操作按钮只显示合法状态转换。重要的个人资料按权限遮蔽。

### 共通状态

每页定义初次加载、无数据、无搜索结果、权限不足、字段校验失败、服务不可用、保存中和保存成功状态。所有异步动作显示进度；失败可重试且不重复产生副作用。

## 4. M00 管理员、用户与权限

### 登录页
商店名称/品牌、账号、密码、登录按钮、失败提示和锁定说明。店主/管理员必须通过 MFA；支付配置、退款执行等高权限角色按策略启用 MFA。重置账号走已配置的安全找回机制。登录错误不得区分有效账号是否存在。

### 员工列表与编辑
列表列出姓名、邮箱/账号、角色、状态、最后登录和创建时间。新增员工先发送邀请；编辑员工可改角色、停用、强制登出。停用前提示其当前负责的操作和权限。

### 角色权限页
按模块展示权限组：读取、创建、编辑、删除/归档、导出、退款/财务操作、权限管理。隐私请求另设读取、身份核验、审批、处理、导出权限；顾客档案读取或订单查询不会自动授予隐私请求或资料导出权限。系统默认角色可复制，不可被意外删除。最小权限为默认；后台 API 每次请求都做权限检查。

### 审计日志
筛选时间、操作者、对象、动作和结果；详情显示变更字段差异，敏感字段掩码。日志只读、不可由店铺管理员编辑或删除。

## 5. M01 店铺、语言与市场设置

### 开店初始化
按顺序完成店铺名称/品牌、地区/时区/币种、启用语言、客服方式、付款配送、首批商品和预览。每一步有稍后完成入口；交易所需资料未完成时显示“尚未满足上线条件”。

### 店铺资料
品牌名、标志、域名、客服资料、页脚政策链接、默认语言、时区和显示币种。域名/TLS 为部署运维配置时，商家后台只显示状态或配置说明，不暴露证书私钥。

### 语言设置
启用简体中文、繁体中文、英文；设默认语言和前台可切换语言。分别显示商品、内容和政策翻译完整率。缺译处理策略需由业主决定：回退默认语言、隐藏对象或阻止发布。

### 市场规则
列出目标地区、审核状态、配送/付款可用性和负责人备注。未审批时状态明确为“待审核/关闭”，不得显示为已获准。具体商品和年龄规则由商家配置与审核。

## 6. M02 前台预览与定制交接

预览页区分“店铺内容/陈列配置预览”和“客户前台设计稿预览”。后台可改品牌资料、导航、主题注册的首页/专题陈列区块、商品选择与排序、政策文本；客户代码决定页面结构和未注册的特殊组件。

- 顶部选择桌面/窄屏、语言和预览状态。
- 展示最近预览时间、前台/API 版本和内容更新时间。
- 陈列编辑器仅允许主题注册的区块：可新增/隐藏区块、拖动区块排序、为区块选择商品/分类/专题内容、设置手工商品优先级或已支持的动态排序规则。
- 桌面/手机、三种语言及草稿/正式版本均可预览；未发布草稿仅管理员可见；发布产生版本与审计记录，可撤回到上一版本。
- 不提供任意代码、脚本或 CSS 编辑；客户主题没有的特殊区块进入客户设计开发清单。
- 预览数据与正式上架数据一致，但草稿内容仅管理员可见。
- 发布前检查图片、翻译、SEO 和关键链接完整性。

## 7. M03 商品、分类、规格与搜索

### 商品列表
列包括主图/名称/SKU、状态、分类、变体数、价格区间、库存摘要、更新时间。筛选草稿/上架/归档/缺图/缺译/缺货。批量动作支持发布、下架、导出；批量价格或库存改动需二次确认和审计。

### 商品编辑
分段为基础资料、多语言内容、图片、分类/品牌、规格变体、价格、库存、SEO、发布设置。以语言标签显示翻译完成度；保存草稿与发布分离。规格组合需要生成唯一 SKU；重复 SKU 和无效价格在保存前阻断。

### 分类与品牌
支持层级分类、排序、可见状态、翻译和 SEO；有商品的分类不能无提示删除。品牌页维护名称、标志、说明和关联商品。

### 规格属性
定义类型、选项、是否变体维度、是否筛选项、显示顺序和可翻译标签。已有商品使用的属性变更需列出影响，避免删除属性造成 SKU/筛选丢失。

## 8. M04 内容管理

页面/FAQ/公告列表显示标题、类型、语言完成状态、草稿/发布、更新时间和编辑者。编辑器分为内容、图片/链接、SEO、翻译和版本信息；预览按客户前台路由打开隔离的预览版本。

- 通过安全的结构化块管理标题、段落、图片和按钮，不允许插入任意脚本。
- 发布支持定时仅在计划纳入后启用；MVP 可先即时发布和撤回。
- 导航配置校验目标 URL、排序和未发布页面链接。
- 政策页面保留修改时间/版本，历史内容可追溯。
- SEO 面板按语言维护标题、描述、社交预览和索引策略；canonical/alternate 由已验证的生产域名、启用语言和路由生成。重定向表展示来源、目标、状态码、创建人和最近验证结果；冲突/循环保存时阻止并说明原因。
- sitemap 预览只含已发布且允许索引的正式 URL；预览环境、草稿、管理页、购物袋和结账页始终 noindex。

### 前台陈列编辑器

使用客户主题登记的区块目录，而不是任意画布。运营人员可选择横幅、商品集合、分类入口、专题内容等主题已支持区块；增删/隐藏区块、拖动区块顺序、选择商品或分类、手动调整商品顺序/置顶，或选用新品/销量/价格等已开放排序。商品选择器需提供搜索/分类/库存筛选，并解释草稿、归档、市场不可售等不可选原因；切换到动态排序后禁用手动优先级控件，并显示候选范围、数量上限和同值排序。支持桌面/手机及三语预览、保存草稿、即时发布、按店铺时区定时发布/撤下和撤回历史版本。页面列出已发布版本、计划状态和操作者；回滚前要求确认，恢复时创建新版本。发布前检查启用语言、图片、链接及商品可售状态；定时冲突/任务失败时保留当前线上版本并通知管理员。已发布商品后续下架时，手动配置保留并标记异常，动态规则跳过并补足候选；前台始终重验可售资格。缺货商品依店铺设置显示售罄且不可购买。客户专属的新组件须先由前端开发注册。

## 9. M05 商品导入与导出

### 导入任务
新建导入 -> 选择模板/文件 -> 字段映射 -> 校验预览 -> 确认导入 -> 行级结果。预览显示新增/更新、无效 SKU、重复项、缺少语言、错误图片地址和价格格式。

- 在确认执行前不修改正式商品。
- 支持明确的“只新增”或“按 SKU 更新”，不提供模糊覆盖。
- 大任务显示进度、成功/失败行数，可下载错误报告后修正并重传。
- 重试同一任务必须防止重复创建；操作由权限控制并记录审计。
- 文件大小、格式、编码和公式注入按安全规则校验。

### 导出任务
选择商品/订单/库存/顾客资料类型及允许字段，确认权限和数据量；后台生成后提供限时下载。顾客资料导出默认更严格授权并写审计。

## 10. M06 购物袋与访客结账

这是顾客端模块，不设计一个能绕过前台交易校验的后台“代下单”按钮。后台可检查结账设置和购物流程状态，但所有订单仍通过服务端结账规则创建。

页面交互和状态见 [顾客前台页面设计](STOREFRONT.md)；核心配置由 M01、M08、M09 提供。客服人工建单若未来需要，须单独定义权限、库存、付款状态和审计逻辑。

## 11. M07 订单与履约

### 订单列表
搜索订单号、日期、付款状态、订单状态、配送方式和顾客联系方式（权限允许时）。默认排序最新订单；列包括订单号、时间、顾客、金额、付款、配送、订单状态。支持导出仅限相应权限。

### 订单详情
顶部显示编号、时间、订单状态和允许的下一动作。内容区显示商品快照、联系/配送资料、金额拆分、优惠快照、付款/配送记录、顾客备注、管理员内部备注和时间线。

### 操作规则
- 状态按钮依据状态机动态显示；不可逆操作要求确认。
- 付款状态和履约状态分开呈现，不能将“已发货”视为已付款。
- 电话/地址默认遮蔽；查看完整信息和复制均按权限审计。
- 支持备注和通知重发；不允许直接改历史订单商品价格。
- 订单详情可创建/查看 M16 售后案件；取消、退款、退货、换货在售后模块按独立状态机与权限处理。

## 12. M08 付款设置和交易记录

### 付款设置
列出货到付款和各已集成服务商，显示启用状态、支持地区、测试/生产模式和凭证配置状态。授权管理员可在后台填写服务商商户号/API 凭证；服务端将密钥写入密钥管理服务，数据库只存引用，后台保存后不回显明文。显示服务商账户连接和结算银行账户脱敏状态；银行账户实际绑定由客户在服务商商户后台完成，本系统不保存完整银行账号或网银凭证。启用前运行配置检查，测试交易与生产切换分离。

### 交易列表/详情
显示交易编号、关联订单、金额币种、服务商、当前状态、创建时间。详情展示脱敏请求/回调摘要、验签结果、外部交易号、重试次数和失败原因；不显示卡号/CVV/密钥。

- 回调事件按唯一事件号去重。
- 交易金额必须与订单应付金额和币种一致。
- 退款入口按 M16 售后流程出现；服务端核验支付服务能力、已收金额、累计退款和操作者权限。
- 对账差异可导出并标为待人工核对。
- 结算导入页先预览文件、币种、期间、重复行和无法匹配的交易；确认后建立对账批次。差异解决要填原因，不能自动改写订单或付款事实。

## 13. M09 配送与运费

配送区域列表显示名称、适用国家/地区、状态、优先顺序和匹配方式。规则编辑器配置固定费、按件/重量/金额等费率，免运门槛和不可配送边界；暂不包含的规则不展示。

- 有重叠区域时显示优先级和冲突警告。
- 结账报价由后端根据地址与购物车计算。
- 费率变更不覆盖既有订单的配送快照。
- 物流接口未接入时，订单详情使用人工履约状态和运单号输入。

## 14. M10 顾客/会员后台资料

列表显示姓名/联系资料（掩码）、订单次数、消费汇总、来源、标签和最后下单时间。支持按邮箱/电话精确查找，避免大列表泄露资料。

档案包含基本资料、订单、标签、沟通记录（若启用）和营销同意状态/来源/时间。会员页另管理等级、积分规则、积分流水、权益和优惠券关联。顾客用 OTP 自愿访问自己的会员中心；后台调整积分、等级或导出需授权并审计。可合并重复顾客档案需审批，不得删除订单历史。

### 个人资料请求队列

`/admin/privacy-requests` 按请求编号、顾客脱敏标识、请求类型、接收时间、状态和负责人显示待办；只有获授权的隐私专员/管理员可查看必要资料或生成导出。详情页记录身份核验方式与结果、责任人、客户规定的处理时限、请求涉及的数据范围、决定理由及操作时间。身份未核验时禁止导出、修改或删除；营销退订立即生效，不等待其他请求审批。删除/匿名化须展示将保留的交易事实和例外依据，拒绝或延期必须填原因；导出文件限时可下载并自动过期。所有查看、审批、下载、完成和拒绝动作写入受限审计日志。

## 15. M11 优惠券与促销

列表显示代码、类型、优惠值、有效期、适用范围、使用数/上限和状态。创建表单包括：

- 固定金额或百分比折扣；币种一致性。
- 最低消费、总使用次数、每顾客限制。
- 商品/分类范围、排除范围、适用市场。
- 开始/结束时间和启用状态。
- 是否允许与其他折扣叠加（需明确默认）。

批次发放页面生成或导入代码，显示生成数量、重复/失败项、分配方式和发放状态。发送渠道需要顾客同意和通知设置；未配置渠道时只生成代码，不假装已发送。核销详情链接回订单但不暴露不必要顾客资料。

## 16. M12 库存与预警

库存总览按 SKU 展示现货、预留、可售量、预警阈值、最近变更和状态。筛选低库存/缺货/即将补货。库存详情可调整数量，但必须选择原因、填数量并确认；生成不可编辑的库存变动流水。

- 可售量规则为现货减去有效预留，具体扣减时点需冻结。
- 预警阈值由 SKU 设置，可从商品批量导入。
- 预警列表标明触发阈值和当前数量；已处理可标记，不等同于自动补货。
- 同一订单并发下单不得超卖；后台展示预留过期/释放状态。
- 库存导出需带 SKU 和时间，调整操作记录员工与原因。

## 17. M13 通知与客服资料

通知配置页维护客服联系方式、订单通知渠道和模板。交易通知与营销通知分开显示；邮件/短信/WhatsApp 集成状态、测试发送、失败原因有明确提示。

模板编辑器使用安全变量列表，例如订单号、顾客称呼、金额、付款说明和追踪号；预览要用样例数据且区分当前语言。缺少必需变量时不能发布。发送日志列出订单、渠道、送达状态、尝试时间、重试与脱敏错误。重试不得重复发送已成功的通知，营销发送遵循同意状态。

## 18. M14 报表和站点分析

### 经营报表
总览显示销售额、订单数、平均订单金额、退款（如纳入）、待处理订单。提供日期范围、时区和币种说明。销售额公式在开发前冻结：是否含税/运费、取消和退款如何扣除。

### 商品/库存报表
商品表现按订单销售与匿名浏览分别呈现；库存报表强调当前低库存、历史变动和预留。避免将访问量误作销量。

### 访问漏斗
从访问、商品查看、加购、开始结账到成功下单。按来源、语言、设备或商品筛选；只显示样本足够的聚合值。订单转化与收入归因需标注采用的模型，不默认首触或末触。

### 导出与空态
无数据时显示日期范围及事件覆盖说明；导出任务可见状态、筛选条件和生成时间。导出权限独立控制。事件同意和留存策略未确认前不得默认无限留存。

## 19. M15 私有部署与运维边界

M15 不是普通店员菜单。实例安装、升级、备份、恢复和密钥轮换由商家技术人员或授权运维人员完成，可通过部署文档/受限运维入口操作。

- 初次部署清单：实例标识、版本、域名/TLS、数据库、对象存储、管理员初始化。
- 健康检查：应用版本、数据库连接、任务队列、磁盘空间、备份最近时间；不展示密钥。
- 升级：先备份，再显示版本差异和迁移计划，运行预检查，确认后发布并检查健康状态。
- 备份/恢复：展示时间、范围、校验状态和目标实例；恢复需二次授权并验证商家实例，避免跨实例覆盖。
- 支持访问：需商家授权、限定时间和权限范围，记录审计。
- 不建设中央商户控制台或跨店业务数据总览。

## 20. M16 售后管理

售后列表提供案件号、订单号、类型、付款/履约状态、负责人和更新时间筛选；详情汇总订单快照、已收金额、累计退款、可退余额、顾客说明、收件质检、支付事件、通知和审计时间线。

案件详情只开放符合当前状态的操作：补资料、批准/拒绝、登记退件、质检、发起退款、记录线下退款、补发/换货和关闭。退款弹窗展示币种、已收、已退和本次金额；服务端再次校验。未收款 COD 取消不产生退款；退回商品需质检后才能生成入库流水。顾客可见状态与内部审核备注分开。详见 [售后页面与交互设计](AFTERSALES.md)。
