## 本轮设计基线

1. 产品面向多个客户逐家私有部署，不设计共享 SaaS 商户总控台。
2. 后台、交易规则和管理流程尽量复用；每家客户前台单独确认页面清单并独立设计开发。
3. 访客购物和结账不需要登录；会员可选用一次性验证码进入会员中心。
4. 首发前台需要简体中文、繁体中文和英文；货币、时区、市场可由独立实例配置。
5. 商品、内容和主题支持的前台陈列由商家后台维护；页面结构和特殊交互由客户前台代码维护。
6. 价格、优惠、库存、运费、订单和支付状态以服务端为准。
7. 烟草客户前台仅作为第一个客户设计案例；商品展示、年龄/市场限制、营销和支付是否可上线须由商家按目标市场确认。
8. HK$、演示数据、示例品牌和示例产品在视觉稿中均为占位，不是系统默认值。

## 页面设计评审方法

每一页按以下问题检查：

- 这页服务哪个用户、帮助他完成哪件事？
- 主操作是否唯一明确？取消/返回/危险操作是否有清楚区分？
- 数据从哪里来，编辑后是否能预览或追溯？
- 空数据、加载中、权限不足、校验错误、网络失败和成功状态是什么？
- 简体、繁体和英文的长文案是否会溢出？
- 窄屏、键盘操作、读屏标签和触控目标是否可用？
- 页面需要记录什么操作审计或分析事件？
- 哪些内容来自后台配置，哪些属于该客户前台定制代码？

尚未确认的业务规则在页面上做配置/待定标记，不能以设计稿暗中替客户定规则。
